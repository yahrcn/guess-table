# Свои картинки для карточек

Положите сюда файл с именем `<id карточки>.jpg` (подойдут и `.jpeg`, `.png`, `.webp`) —
приложение сначала попробует показать его, и только если файла нет, покажет
сгенерированную иллюстрацию. Менять код не нужно, достаточно положить файл с
правильным именем — подхватится само.

Точные id и подписи всех карточек — в [`packages/shared/src/cards.ts`](../../../shared/src/cards.ts).
Например:

```
fictional-01.jpg   → «Алекс Нова»
celebrity-03.jpg   → «Исаак Ньютон»
animal-01.jpg      → «Лев»
profession-05.jpg  → «Повар»
movie-01.jpg       → «Титаник»
game-05.jpg        → «Minecraft»
```

Рекомендуемый размер — квадратное изображение (например 400×400), но любые пропорции
подойдут — картинка обрезается по центру (`object-fit: cover`), не искажаясь.

**Важно про авторские права:** добавляйте только изображения, на которые у вас есть
права (свои фото/рисунки, купленный сток, материалы с лицензией, явно разрешающей такое
использование). Этот проект не скачивает и не хранит никаких изображений сам — вся
ответственность за то, что вы сюда положите, на вас.

Эта папка — часть статики клиента (Vite `public/`), поэтому содержимое должно попасть и
в собранный `packages/client/dist/` при `npm run build`/деплое.
